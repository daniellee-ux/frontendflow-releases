# FrontendFlow for Mac

[Download the latest release](https://github.com/daniellee-ux/frontendflow-releases/releases/latest)

Explore HTML prototypes, review their screens and flows, and collaborate with your team.

## Install

Apple silicon Mac, macOS 13 or later. Open the DMG and drag FrontendFlow into Applications. Node/npm are included. Install Google Chrome to import and explore HTML prototypes.

The installer is Developer ID signed and Apple notarized. Projects and credentials stay in `~/Library/Application Support/FrontendFlow/` across app updates.

## Updates

Starting with 0.2.1, FrontendFlow checks for updates automatically, downloads verified updates, and installs them when you quit. Use **FrontendFlow → Check for Updates…** to update sooner or **Automatically Update** to change the preference.

If you have the original 0.2.0 app, install 0.2.1 once to enable future automatic updates.

This repository hosts installers and Sparkle update feeds. Application source is maintained separately. Release notes include known limitations and the corresponding source revision.
